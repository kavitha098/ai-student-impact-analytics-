# AI Student Impact Analytics

Enterprise-grade Streamlit analytics platform
for analyzing the impact of Generative AI on
student performance, retention, dependency,
and burnout risk.

## Features

- Executive Dashboard
- Deep Analytics
- AI Usage Insights
- Burnout Prediction
- GPA Forecasting
- Policy Impact Analysis
- Interactive Plotly Visualizations

## Run

pip install -r requirements.txt

streamlit run app.py
